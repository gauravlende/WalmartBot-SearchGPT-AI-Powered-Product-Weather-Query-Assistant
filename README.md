# WalmartBot & SearchGPT

An AI-powered web application featuring two intelligent assistants:

## 🛒 WalmartBot
Get real-time product information from Walmart using simple natural language prompts. 
Just ask, and retrieve:
- Product prices
- Direct product URLs
- Quick product search results

## 🌤️ SearchGPT
An AI assistant that provides live weather updates for New York City through 
conversational prompts — no need to browse multiple weather sites.

## Features
- Natural language / prompt-based querying
- Real-time data retrieval
- Simple, user-friendly web interface
- Modular design (two independent bots in one app)


## How It Works
1. User enters a prompt (e.g., "What's the price of iPhone 15 on Walmart?")
2. The relevant bot processes the query
3. Results are fetched and displayed instantly

## Future Scope
- Expand product search beyond Walmart
- Add weather support for more cities
- Improve response accuracy with fine-tuned prompts
